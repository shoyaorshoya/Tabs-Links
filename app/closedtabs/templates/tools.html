Tools

Save from any page in one click

Drag this button to your browser's bookmarks bar:

＋ Save to ClosedTabs

  1. No bookmarks bar? Press Cmd + Shift + B (Chrome) to show it.
  2. On any page you want to keep, click ＋ Save to ClosedTabs. A small window opens.
  3. Type why you save it (and a project, if any), then press Enter. The window closes by itself.
  4. Tip: select text on the page first. It's saved as a quote with the link.

The button only works while ClosedTabs is running on this computer. If the browser blocks the small window, allow pop-ups for the sites you save from (or for all sites).

Claude

Let Claude search, read and add to your library.

  • Claude desktop app (Mac): double-click Connect-Claude.command in the ClosedTabs folder, then quit and reopen Claude.
  • Claude Code: claude mcp add --transport http closedtabs http://localhost:3000/mcp

Then ask, for example: “What did I save about onboarding? Give me the 5 best with links.”
